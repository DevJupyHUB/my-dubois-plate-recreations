**DuboisChallenge**

The challenge celebrates Du Bois’s data viz legacy by recreating his 1900 Paris Exposition visuals using modern tools.

All information about the challenge, including data, is available [here](https://github.com/ajstarks/dubois-data-portraits/tree/master/challenge)
